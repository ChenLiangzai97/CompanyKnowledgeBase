# 备忘标题

> 本文件是模板，不是实际业务备忘。新建时替换占位说明，未知信息写待确认。

## 原始信息

保留用户提供的原话、消息或链接，不把 Agent 的补充写成原话。

## 检索摘要

由 Agent 提取一句话摘要及必要的别名、分支名、特性名等检索线索。推断须标明。

## 来源与适用范围

- 来源：实际消息链接、文档链接或“用户提供”；无法取得来源链接时如实说明。
- 消息发生日期：待确认；与记录日期区分。
- 涉及仓库／分支／版本／特性：待确认。
- 当前有效性：未核查；记录本身不证明仍然有效。

## 补充与关联

按需记录后续信息的日期与来源，关联已有知识或后续备忘。有真实目标时再添加链接；无目标时写待确认。
