# 测试与验收

在仓库根目录运行：

```bash
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 scripts/check_knowledge.py
git diff --check
```

自动测试使用临时目录验证：正常空库与真实条目、中文及重复标题、代码块排除、路径编码与目录入口、无效链接、仓外路径与符号链接、元数据与 ID、导航覆盖、只读性、CLI 的根目录和退出码。测试不联网，不在真实知识目录写入业务条目。

脚本测试通过只证明这些结构行为。来源可靠性、记录是否归入正确主题、回答是否准确和 Agent 是否遵守授权边界，需要单独按 [行为场景](behavior-cases.md) 验收。每次规则变更都应审阅受影响场景，必要时在临时副本中真实试跑。

执行记录应注明输入、实际动作、内容差异与结果。只审阅规则时写“静态审阅”；未启动真实 Agent 时写“未实测”。示例输入不等于已执行证据，不能据此填写“全部通过”。

初始交付的实际范围见 [2026-11-09 验证记录](validation-2026-11-09.md)。
